# LazyTV Engine v1

Bazë për LazyTV: frontend HTML + katalog burimesh M3U.

## Struktura
- `index.html` — ndërfaqja LazyTV
- `data/sources.json` — burimet M3U
- `data/channels.json` — katalogu i kanaleve (plotësohet nga engine)
- `data/vod.json` — filma/seriale nga burime të autorizuara
- `live/`, `vod/`, `assets/` — hapësira për eksportet

Ky version përdor vetëm burime publike. Më pas mund të shtohen M3U/API për të cilat ke të drejtë përdorimi.
